# Product Requirements Document

## Product

CoursePilot is a student course registration and course catalogue application.

## Current Feature

The current implemented feature is the student course catalogue.

Students should be able to:

- View course list
- Search courses by code or title
- Filter courses by department
- Filter courses by semester
- Show only available courses
- Show mandatory courses
- View course details such as instructor, credits, seats, prerequisites, and schedule

## Technical Direction

The frontend is built with React and TypeScript. The backend is built with FastAPI. The data layer uses SQLAlchemy with a relational database structure.
